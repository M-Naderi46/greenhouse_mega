# کنترلر گلخانه — Arduino Mega 2560 (C خالص، کتابخانه‌ای، VS Code)

> این نسخه برای **Arduino Mega 2560 (ATmega2560، ۱۶ مگاهرتز، ۵ ولت)** است و بدون هستهٔ Arduino و با C خالص (avr-gcc) نوشته شده است. منطق برنامه با نسخهٔ ATxmega یکی است؛ فقط لایهٔ سخت‌افزار (`lib/hal`، پین‌ها، ADC، تایمر…) تغییر کرده است. با کابل USB و بوت‌لودر خود برد برنامه‌ریزی می‌شود؛ پروگرامر لازم نیست.

آبیاری خودکار، کنترل فن/هیتر/لامپ رشد، سنسور نور BH1750 (لوکس)، RTC، فلومتر، سوئیچ سطح مخزن، سنسور دما و رطوبت **AHT20 / DHT12 / DHT11 (انتخاب از منو)**، LCD 20×4 و ثبت داده روی UART.

## ساختار پروژه

```
greenhouse_mega/
├─ include/user_config.h   ← پین‌ها، آدرس‌ها، مقادیر پیش‌فرض (فقط همین فایل را ویرایش کنید)
├─ src/main.c              ← حلقهٔ اصلی
├─ lib/
│  ├─ hal/                 ← تایمر، I2C (TWI)، UART، GPIO
│  ├─ lcd_i2c/  rtc_ds3231/
│  ├─ air_sensor/          ← سنسور دما/رطوبت هوا: AHT20، DHT12، DHT11 (نوع از منو)
│  ├─ analog/              ← ADC و تبدیل به درصد
│  ├─ soil_sensor/         ← یک یا دو سنسور رطوبت خاک
│  ├─ light_sensor/        ← BH1750 (لوکس)
│  ├─ tank/                ← سوئیچ شناور مخزن
│  ├─ flow_meter/  valve/  buzzer/  buttons/  outputs/
│  ├─ settings/            ← تنظیمات + قابلیت‌ها در EEPROM با CRC
│  ├─ sensors/             ← جمع‌کنندهٔ دادهٔ سنسورها
│  ├─ irrigation/          ← آبیاری و تشخیص خطا
│  ├─ climate/             ← فن، هیتر، لامپ رشد
│  ├─ datalog/             ← خط CSV روی UART
│  └─ ui/                  ← صفحهٔ اصلی و منو
├─ platformio.ini          ← روش PlatformIO
├─ Makefile  .vscode/      ← روش Makefile
├─ PARTS_LIST.md
```

## راه‌اندازی در VS Code (دو روش، هر کدام را خواستید)

### روش ۱: PlatformIO (پیشنهادی، بدون نصب دستی کامپایلر)

1. افزونهٔ **PlatformIO IDE** را در VS Code نصب کنید (کامپایلر و avrdude را خودش دانلود می‌کند).
2. پوشهٔ `greenhouse_mega` را باز کنید؛ فایل `platformio.ini` شناسایی می‌شود.
3. برد Mega را با کابل USB وصل کنید و دستورها (یا دکمه‌های نوار پایین VS Code):
   ```
   pio run                    کامپایل (برد megaatmega2560)
   pio run -t upload          آپلود از راه USB
   pio run -t size            میزان مصرف حافظه
   pio device monitor         مشاهدهٔ لاگ CSV (۹۶۰۰ بیت بر ثانیه)
   ```
4. اگر پورت درست پیدا نشد، در `platformio.ini` خط `upload_port = COM3` را فعال کنید.
5. پرچم `-Iinclude` در `build_flags` الزامی است: PlatformIO پوشهٔ `include/` را فقط به `src/` می‌دهد، نه به کتابخانه‌های `lib/` (بدون آن خطای `user_config.h: No such file or directory` می‌گیرید).
6. PlatformIO هنگام باز کردن پروژه، `.vscode/c_cpp_properties.json` را خودش دوباره می‌سازد؛ این طبیعی است.

### روش ۲: Makefile

1. نصب: **avr-gcc + avr-libc**، **make**، **avrdude** و افزونهٔ **C/C++**.
2. کامپایل: `Ctrl+Shift+B` ← `build/greenhouse.hex`
3. آپلود: `make flash PORT=COM3` (در لینوکس `PORT=/dev/ttyACM0`). از پروتکل `wiring` (بوت‌لودر Mega) استفاده می‌شود.

هر دو روش از همان پوشه‌های `include/`، `src/` و `lib/` استفاده می‌کنند و برنامهٔ یکسانی می‌سازند.

## اتصالات پیش‌فرض (قابل تغییر در `user_config.h`)

پین‌ها در `user_config.h` به شکل `A, 0` (حرف پورت، شمارهٔ بیت) نوشته می‌شوند. شمارهٔ پین روی برد Arduino Mega در ستون آخر آمده است.

| عملکرد | پایهٔ AVR | پین روی برد Mega |
|--------|-----------|-------------------|
| سنسور خاک ۱ / ۲ (آنالوگ) | PF0 / PF1 | A0 / A1 |
| I2C: SDA / SCL (LCD، RTC، BH1750، AHT20، DHT12) — ثابت | PD1 / PD0 | D20 / D21 |
| UART TX (ثبت داده) — USART0، همان USB | PE1 | D1 (TX0) |
| شیر برقی | PA0 | D22 |
| فن / هیتر / لامپ رشد | PA1 / PA2 / PA3 | D23 / D24 / D25 |
| پمپ آب (حالت تانکر) | PA4 | D26 |
| بازر | PA5 | D27 |
| فلومتر (وقفهٔ INT4) | PE4 | D2 |
| سوئیچ شناور مخزن | PC0 | D37 |
| دکمه‌ها MODE / UP / DOWN | PC1 / PC2 / PC3 | D36 / D35 / D34 |
| DHT11 (فقط اگر نوع DHT11 انتخاب شود) | PL0 | D49 |
| تغذیهٔ قابل قطع سنسور خاک (اختیاری) | PA7 | D29 |

- فلومتر باید روی یکی از پین‌های وقفهٔ PORTE (`INT4..INT7`) باشد؛ در `user_config.h` هر دو `FLOW_PIN` و `FLOW_INT_NUM` را با هم تغییر دهید.
- لاگ UART روی USART0 است (همان پورت USB). برای ESP8266/ESP32 پین D1 را به RX آن وصل کنید و هنگام آپلود برنامه، ESP را جدا کنید.

## انتخاب نوع سنسور دما و رطوبت

منو ← FEATURES ← `Air temp/hum sensor` ← با UP/DOWN یکی از سه نوع را انتخاب کنید ← **Save and exit**:

| نوع | اتصال | محدودهٔ دما | دقت دما / رطوبت |
|-----|--------|--------------|-------------------|
| **AHT20** (پیش‌فرض) | I2C، آدرس 0x38 | ۴۰- تا ۸۵ | ±۰٫۳ / ±۲٪ |
| DHT12 | I2C، آدرس 0x5C | ۲۰- تا ۶۰ | ±۰٫۵ / ±۵٪ |
| DHT11 | یک‌سیم، پین PL0 (D49) | ۰ تا ۵۰ | ±۲ / ±۵٪ |

- **دما با یک رقم اعشار و بر حسب سانتی‌گراد:** سطر دوم صفحهٔ اصلی مثل `T24.3C H55% L12345` است (دما، رطوبت، لوکس)، در منو کنار حد فن/هیتر `(now 24.3C)` دیده می‌شود و ستون دمای لاگ هم `24.3` است. AHT20 و DHT12 دقت ۰٫۱ دارند؛ DHT11 فقط عدد صحیح می‌دهد (`24.0`). منطق فن، هیتر و یخ‌زدگی با دمای گردشدهٔ صحیح کار می‌کند و حدهای منو عدد صحیح می‌مانند.
- تغییر نوع بعد از Save بلافاصله اعمال می‌شود (خوانش‌های سنسور قبلی دور ریخته می‌شود). اگر سنسور انتخاب‌شده وصل نباشد، پس از حدود ۱۵ ثانیه `T--.-C` نشان داده می‌شود.
- AHT20 و DHT12 روی همان I2C مشترک با LCD و RTC هستند (SDA/SCL؛ اگر ماژول‌ها پول‌آپ ندارند ۴.۷k به ۵ ولت). AHT21 با AHT20 سازگار است.
- AHT20 هر خوانش ۸۰ میلی‌ثانیه طول می‌کشد (هر ۳ ثانیه)، بدون مشکل برای حلقهٔ اصلی. داده با CRC-8 بررسی می‌شود و خوانش‌های نادرست دور ریخته می‌شوند.
- نوع پیش‌فرض اولیه را `DEFAULT_AIR_SENSOR` در `user_config.h` تعیین می‌کند (۰ = DHT11، ۱ = DHT12، ۲ = AHT20).

## نحوهٔ کار

- **آبیاری:** خاک < حد پایین → شیر باز؛ بسته شدن با حد بالا، سقف لیتر یا سقف زمان. فقط در بازهٔ ساعتی مجاز، بالاتر از دمای یخ‌زدگی و پس از زمان استراحت. با دو سنسور، میانگین (یا خشک‌ترین) ملاک است و خرابی یکی، دیگری را از کار نمی‌اندازد.
- **خطاها:** NO FLOW (شیر باز ولی آب نیست)، LEAK (شیر بسته ولی آب جاری است) → بازر و ریست با UP. TANK EMPTY → آبیاری قطع می‌شود و با پُر شدن مخزن خودکار برمی‌گردد.
- **پمپ آب (حالت تانکر):** فقط وقتی شیر باز است کار می‌کند؛ ۲ ثانیه **بعد** از باز شدن شیر روشن می‌شود (پمپ روی لولهٔ بسته کار نکند) و هنگام توقف، **اول پمپ خاموش و بعد شیر بسته می‌شود**. با خالی شدن مخزن، پمپ و شیر قطع می‌شوند. اگر پمپ روشن باشد ولی آب جاری نشود (پمپ خشک‌کار یا لولهٔ مسدود)، بعد از ۱۰ ثانیه خطای NO FLOW و قطع هر دو.
- **فن:** روشن در دمای ≥ حد فن یا رطوبت بالا (رطوبت فقط وقتی هوا سرد نیست)، با هیسترزیس.
- **هیتر:** روشن در دمای ≤ حد هیتر؛ هیچ‌وقت هم‌زمان با فن روشن نمی‌شود.
- **لامپ رشد:** فقط در بازهٔ ساعتی تعریف‌شده: روشن زیر «Lamp ON lux»، خاموش بالای «Lamp OFF lux». با خرابی BH1750 یا RTC لامپ خاموش می‌ماند.
- **خرابی سنسور هوا:** هیتر خاموش، فن روشن (قابل تغییر با `FAN_ON_SENSOR_FAIL`).
- حداقل زمان بین دو تغییر رله (فن/هیتر ۳۰ ثانیه، لامپ ۵ دقیقه) از رله‌ها محافظت می‌کند.

## صفحهٔ اصلی

دکمهٔ **DOWN** بین دو صفحه جابه‌جا می‌شود (بعد از ۳۰ ثانیه برمی‌گردد): ۱) ساعت، دما، رطوبت، لوکس، خاک ۲) وضعیت فن/هیتر/لامپ/مخزن. سطر چهارم همیشه وضعیت آبیاری یا خطا را نشان می‌دهد.

## منوی تنظیمات

**MODE** (رها کردن) وارد منو می‌شود. **MODE** = گزینهٔ بعد، **نگه داشتن MODE (۱ ثانیه)** = بخش بعد، **UP/DOWN** = تغییر مقدار (نگه داشتن، تغییر را سریع می‌کند).

| بخش | گزینه‌ها |
|-----|---------|
| **FEATURES** | دو **پیش‌تنظیم**: `Place` (UP = محیط باز: فن/هیتر/لامپ خاموش، DOWN = گلخانه) و `Water source` (UP = تانکر + پمپ، DOWN = آب شهری بدون پمپ). سپس روشن/خاموش کردن تک‌تک قابلیت‌ها: آبیاری خودکار، سنسور خاک ۲، سنسور نور، سوئیچ مخزن، **پمپ آب**، فن، هیتر، لامپ رشد، ثبت UART (**UP = ON، DOWN = OFF**) |
| IRRIGATION | آستانه‌های رطوبت، بازهٔ ساعتی، سقف لیتر و زمان، فاصلهٔ آبیاری، حد یخ‌زدگی، پالس بر لیتر |
| SOIL CAL | کالیبراسیون هوا/آب سنسور ۱ (و ۲): با UP مقدار فعلی ذخیره می‌شود |
| CLIMATE | دمای روشن شدن فن و هیتر، رطوبت حداکثر |
| LAMP | ساعت شروع/پایان و آستانه‌های لوکس روشن/خاموش (مقدار فعلی لوکس کنار آن نمایش داده می‌شود) |
| CLOCK | ساعت و **تاریخ شمسی** (روز، ماه با نام، سال ۱۳۷۹ تا ۱۴۷۷) |
| TOOLS | تست شیر/فن/هیتر/لامپ، بازگشت به پیش‌فرض، **Save and exit** |

- گزینه‌های مربوط به قابلیت‌های خاموش، خودکار از منو **پنهان** می‌شوند (مثلاً با خاموش کردن هیتر، «Heater ON at temp» و تست هیتر دیده نمی‌شوند).
- خاموش کردن یک قابلیت، خروجی آن را **خاموش** نگه می‌دارد.
- تغییرات پس از «Save and exit» (MODE) اعمال می‌شوند؛ **DOWN** روی آن گزینه تغییرات را دور می‌ریزد و ۶۰ ثانیه بی‌حرکتی هم همین کار را می‌کند.
- مقدار اولیهٔ قابلیت‌ها از `DEFAULT_*_ENABLED` در `user_config.h` می‌آید (فقط هنگام راه‌اندازی اول یا «Restore defaults»).

## تاریخ شمسی

- تاریخ صفحهٔ اصلی به شکل `1405/08/11` (هجری شمسی) نمایش داده می‌شود و در منوی CLOCK هم روز، ماه (با نام فینگلیش مثل `08 Aban`) و سال شمسی تغییر می‌کند.
- RTC همیشه تاریخ میلادی را نگه می‌دارد (۲۰۰۰ تا ۲۰۹۹)؛ تبدیل در کتابخانهٔ `lib/jalali` انجام می‌شود. با تغییر ماه یا سال، روز خودکار اصلاح می‌شود (مثلاً ۳۱ شهریور ← ۳۰ مهر، ۳۰ اسفند در سال غیرکبیسه ← ۲۹ اسفند) و فقط تاریخ معتبر در RTC نوشته می‌شود.
- الگوریتم عددی دقیق (جدول سال‌های کبیسه بورکوفسکی) است و روی تک‌تک روزهای ۲۰۰۰ تا ۲۰۹۹ میلادی (۳۶۵۲۵ روز) با کتابخانهٔ jdatetime یکسان بود، برگشت شمسی به میلادی بدون خطا بود و ۶۰۰ روز حوالی نوروز با محاسبهٔ نجومی نیز مطابقت داشت.
- برای برگشت به میلادی در `user_config.h` مقدار `DATE_JALALI` را `0` کنید. خط لاگ UART همیشه میلادی (ISO) می‌ماند تا برای نرم‌افزارها قابل پردازش باشد.

## ثبت داده (UART، ۹۶۰۰ بیت بر ثانیه)

هر ۱۰ ثانیه یک خط CSV:
`GH,زمان,دما,رطوبت_هوا,خاک1,خاک2,خاک,لوکس,شیر,پمپ,فن,هیتر,لامپ,مخزن,لیتر_امروز,خطا`
مقدار `-` یعنی سنسور غیرفعال یا خراب است. خطوط شروع‌شده با `#` توضیح هستند.

## استفاده در محیط باز (فضای آزاد)

1. منو ← FEATURES ← `Place: open/greenhs` ← **UP** (محیط باز) ← Save. این کار فن، هیتر و لامپ رشد را خاموش می‌کند و گزینه‌های مربوط به آن‌ها از منو پنهان می‌شوند.
2. آبیاری، فلومتر، سنسور خاک، RTC، ثبت داده و محافظت دمای یخ‌زدگی همچنان کار می‌کنند.
3. در فضای باز، بازهٔ ساعتی آبیاری (`Window start/end`) را روی صبح زود یا عصر بگذارید تا تبخیر کمتر شود. «بارش باران» را سنسور رطوبت خاک نشان می‌دهد؛ اگر خاک خیس باشد آبیاری شروع نمی‌شود.
4. **مهم:** DHT11 فقط ۰ تا ۵۰ درجه را می‌خواند. در هوای زیر صفر (یا گرمای شدید) خوانش ندارد و حفاظت یخ‌زدگی کار نمی‌کند. برای فضای باز **AHT20** (تا منفی ۴۰) یا DHT12 (تا منفی ۲۰) بگذارید و در منو نوع سنسور را عوض کنید. سنسور نور و جعبهٔ کنترل را در برابر باران و آفتاب مستقیم محافظت کنید (جعبهٔ IP65، سایه‌بان).

## حالت تانکر و پمپ آب

1. منو ← FEATURES ← `Water source` ← **UP** (تانکر + پمپ) ← Save. این کار «سوئیچ مخزن» و «پمپ» را روشن می‌کند.
2. **سوئیچ شناور مخزن را حتماً نصب کنید.** بدون آن، پمپ هنگام خالی شدن مخزن خشک‌کار می‌کند؛ تنها حفاظت باقی‌مانده خطای NO FLOW بعد از ۱۰ ثانیه است. منو هم در این حالت «Add tank switch!» نشان می‌دهد.
3. پمپ از پین `PUMP_PIN` (پیش‌فرض PA4 = D26) با رله یا ماسفت راه‌اندازی می‌شود. پمپ DC: ماسفت + دیود فلای‌بک. پمپ ۲۲۰ ولت: رلهٔ مناسب جریان راه‌اندازی پمپ و فیوز.
4. فلومتر را **بعد از پمپ** روی لوله بگذارید تا جریان واقعی اندازه‌گیری شود.
5. تأخیر شروع پمپ با `PUMP_START_DELAY_S` در `user_config.h` تنظیم می‌شود.
6. برای تست: منو ← TOOLS ← `Test valve` ← UP؛ شیر باز می‌شود و پمپ هم (اگر روشن باشد) ۲ ثانیه بعد روشن می‌شود.

## کالیبراسیون

1. **سنسور خاک:** (ADC ده‌بیتی، ۰ تا ۱۰۲۳؛ مقدار هوا معمولاً حدود ۵۵۰ تا ۶۲۰ و آب حدود ۲۵۰ تا ۳۰۰) در هوا ← `CAL probe1: in AIR` ← UP؛ سپس در آب ← `in WATER` ← UP.
2. **فلومتر:** در `Test valve` دقیقاً ۱۰ لیتر آب جمع کنید، لیتر نمایش‌داده‌شده را مقایسه و «Flow pulses/litre» را اصلاح کنید.
3. **BH1750:** کالیبراسیون ندارد. آستانه‌های لامپ را بر اساس لوکس واقعی گلخانهٔ خودتان تنظیم کنید (روز ابری ~۱۰۰۰ تا ۱۰۰۰۰ لوکس).

## نکات مهم

- منطق همهٔ پین‌ها ۵ ولت است؛ مبدل سطح لازم نیست. LCD، فلومتر YF-S201 و سنسور خاک خازنی مستقیم وصل می‌شوند.
- ماژول‌های BH1750 (GY-302) و AHT20 را از نوعی بگیرید که رگولاتور روی برد دارند و ۵ ولت را تحمل می‌کنند؛ در غیر این‌صورت از مبدل سطح BSS138 استفاده کنید.
- **رله‌ها:** بیشتر ماژول‌های رلهٔ ارزان «Active-Low» هستند (ورودی LOW = روشن). در این حالت `*_ACTIVE_HIGH` همان خروجی را `0` کنید.
- **لحظهٔ روشن شدن:** هنگام ریست/آپلود، پین‌ها چند صد میلی‌ثانیه ورودی‌اند و ماژول‌های Active-Low ممکن است لحظه‌ای کلیک کنند. برای بار حساس (پمپ/شیر) یک مقاومت ۱۰k بین سیگنال و پایهٔ غیرفعال بگذارید.
- **واچ‌داگ:** با بوت‌لودر قدیمی Arduino Mega، ریست واچ‌داگ ممکن است باعث ریست بی‌پایان شود. اگر چنین شد، در `user_config.h` مقدار `WDT_ENABLED` را `0` کنید یا بوت‌لودر جدید روی برد بسوزانید.
- تغذیه: ۵ ولت از یک Buck با کیفیت (۱۲ ولت روی VIN برای مدت طولانی رگولاتور برد را داغ می‌کند). گروند همهٔ ماژول‌ها یکی باشد.
- BH1750 را دور از نور لامپ رشد نصب کنید و بدانید تا حدود ۶۵۰۰۰ لوکس را می‌خواند (بالاتر از آن عدد ثابت ۶۵۵۳۵).
- اگر `ADDR` ماژول BH1750 را به VCC بزنید آدرس 0x5C می‌شود که با DHT12 تداخل دارد.
- تایمر ۰، TWI، USART0، ADC و وقفهٔ INT4 توسط کتابخانه‌ها اشغال شده‌اند.
- این نسخه روی سخت‌افزار واقعی آزمایش نشده است؛ کامپایل (Makefile و PlatformIO)، منطق آبیاری/پمپ، دیکودر AHT20 و بالا آمدن فریمور در شبیه‌ساز simavr بررسی شده‌اند. قبل از وصل کردن شیر و پمپ واقعی، ابتدا با LED/رله تست کنید.
